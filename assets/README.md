# Yerel görsel şablonlar

Bu görüntüler proje için sağlanan belge örneklerinden elde edilmiştir.
Uygulama başlık ve mühür eşleştirmesinde bunları yerel olarak okur.

- `receiving_report.png`: Receiving Report No başlığı ve referans barkodu.
- `stamp_blue_1.png`, `stamp_blue_2.png`: mavi mühür örnekleri.
- `stamp_faint.png`: soluk/renksiz mühür örneği.
- `stamp_black.png`: siyah mühür örneği.

Şablonlar uygulamanın çalışması için gereklidir. Kaynak PDF’ler depoya dahil değildir.
